---

## Description

Simple Notes Manager allows you to:

- Add notes from the WordPress admin panel
- View all saved notes in a simple list
- Delete notes if no longer needed
- Display notes on your website using the `[simple_notes]` shortcode

This plugin is lightweight, easy to use, and designed for beginners and professionals alike.

---

## Features

- Admin dashboard interface for managing notes
- Frontend display using a shortcode
- Clean and organized code with OOP structure
- Uses WordPress database best practices
- Safe and secure with proper input sanitization

---

## Installation

1. Upload the `simple-notes-manager` folder to the `/wp-content/plugins/` directory.
2. Activate the plugin through the 'Plugins' menu in WordPress.
3. Go to "Simple Notes" in the admin sidebar to add, view, or delete notes.
4. Use the `[simple_notes]` shortcode anywhere on your website to display saved notes.
